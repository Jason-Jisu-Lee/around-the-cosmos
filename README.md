# Around the Cosmos

A calm idle game. A small dark center of a young universe generates stardust with every pulse, and the bodies orbiting it pay a little more with every pass. Catch what falls through the sky, shape each orbiter, and when progress slows, collapse the universe for permanent power and begin again.

## Run it

The game is in `around-the-cosmos/`. Serve the folder over HTTP:

```bash
cd around-the-cosmos
python -m http.server 3000
```

Then open http://localhost:3000.
